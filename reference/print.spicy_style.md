# Print method for table styles

Prints what a
[`spicy_style()`](https://amaltawfik.github.io/spicy/reference/spicy_style.md)
encodes: for a named theme, the journal, the rules it applies, and the
official document they come from; then the levers themselves.

## Usage

``` r
# S3 method for class 'spicy_style'
print(x, ...)
```

## Arguments

- x:

  A `spicy_style` object.

- ...:

  Additional arguments (currently ignored).

## Value

Invisibly returns `x`.
