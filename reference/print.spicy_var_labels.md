# Print a `var_labels()` value

Prints the labels as the plain named character vector.

## Usage

``` r
# S3 method for class 'spicy_var_labels'
print(x, ...)
```

## Arguments

- x:

  A `spicy_var_labels` object, from
  [`var_labels()`](https://amaltawfik.github.io/spicy/reference/var_labels.md).

- ...:

  Passed on to [`print()`](https://rdrr.io/r/base/print.html).

## Value

`x`, invisibly.
