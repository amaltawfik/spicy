# Print a codebook

Prints the variable list of a
[`code_book()`](https://amaltawfik.github.io/spicy/reference/code_book.md)
object in the console, with its headers in the language the codebook was
built in.

## Usage

``` r
# S3 method for class 'spicy_codebook'
print(x, ...)
```

## Arguments

- x:

  A `spicy_codebook` object, from
  [`code_book()`](https://amaltawfik.github.io/spicy/reference/code_book.md).

- ...:

  Ignored.

## Value

`x`, invisibly.
